# Elucida — Vyshakh Nair

Personal portfolio for **Vyshakh Nair** — offensive security engineer. A bright, playful
multi-page site: a draggable-card home, a dedicated page per project, and an about page.

**Live:** https://vyshakhnair.github.io/elucida/

Plain static site (no build step). Home hero uses Matter.js (via CDN) for the draggable cards;
everything else is HTML/CSS. No WebGL — runs everywhere.

- `index.html` — home (draggable project cards + work grid)
- `work/*.html` — one case-study page per project
- `about.html` — about + services
- `css/site.css`, `js/site.js` — shared
